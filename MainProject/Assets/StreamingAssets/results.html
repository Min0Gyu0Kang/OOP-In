Commands
Run code in the editor to see results here.

Grid coordinates are x (column) and z (row), from 0 to 4. Commands run in order; a failed command is skipped and the rest continue.

Bridge.Plow(x, z)

  • Empty plot: shows the cube.
  • Planted plot: clears the plant (not counted).
  • Fails if the plot is already plowed.

Bridge.Remove(x, z)

  • Hides the cube; clears any plant (not counted).
  • Fails if the plot is empty.

Bridge.Plant(x, z, "name")

  • Places the plant on a plowed plot.
  • Fails on an empty plot, an already planted plot, or an unknown name.

Bridge.Harvest(x, z)

  • Removes the plant and adds 1 to its harvest count.
  • Fails on an empty plot or a plot with nothing planted.

Each run

  • Starts from an empty farm: cubes hidden, plants and counts cleared.
  • Python errors stop the script and are underlined in the editor.
